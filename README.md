The dog's defence, in one line (104 characters): the essay accused him of eating
the homework, so he ate it — and now he is taking the defamation very seriously.
A first-person excuse with a meta twist: the crime only happened because the
homework said it did.

## Run it

```sh
node main.ts
```

This validates the entry (1–200 characters, a single line, no trailing whitespace),
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (and to `/output/entry.txt` when that
directory is writable), verifies the written file by reading it back, and prints
the line to stdout.
